# SleepFM

## About

This project is a repackaging of the [SleepFM repository](https://github.com/zou-group/sleepfm-clinical) with the goal of making it easier to use in Python applications. SleepFM is a foundation model for sleep and can be used for multiple sleep-related tasks, including sleep staging, apnea detection, and disease risk prediction.

## Installation

### User Setup

You can install SleepFM directly from this repository using `uv`:

```bash
uv add git+https://github.com/ashenafee/brainhackto-2026@refactor-sleepfm
```

### Development Setup

1. Clone the repository:

```bash
git clone https://github.com/ashenafee/brainhackto-2026.git
```

2. Select the correct branch:

```bash
git checkout refactor-sleepfm
```

3. Navigate to the project directory:

```bash
cd brainhackto-2026/sleepfm
```

4. Create the virtual environment and install dependencies:

```bash
uv sync
```
